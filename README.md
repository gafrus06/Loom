Стек:
Frontend: React.
Backend: Java 21 и Spring Boot.
Архитектура: микросервисная.
Инфраструктурные компоненты: API Gateway Spring Cloud.
Хранение данных: PostgreSQL.
Кеширование и ускорение: Redis.
Событийное взаимодействие: Apache Kafka.
Контейнеризация: Docker.
